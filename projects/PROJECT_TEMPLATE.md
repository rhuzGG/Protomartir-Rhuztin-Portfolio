# Project detail page content template

Create `projects/<project-slug>/index.html` for each real project and include:

- Project title, category, year, status, and your role
- Overview and the problem you set out to solve
- Your solution and key features
- Technologies used
- Optimized screenshots with descriptive alt text
- Only links that exist: live project, source code, demo, or documentation

Keep navigation and shared CSS consistent. Update the matching record in `js/projects.js` to point to the detail page when one exists.
